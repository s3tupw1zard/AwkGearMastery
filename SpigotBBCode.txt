[CENTER][SIZE=5][B]A plugin that adds a leveling system to any item.[/B][/SIZE]

[SIZE=5][B]Features[/B][/SIZE][/CENTER]
[LIST]
[*]Built against Paper 26.3 (recommended/gameplay-tested); compatible older servers may load from API 1.21.11, Java 25 required
[*]Supports Folia.
[*]No required dependencies; PlaceholderAPI is optional.
[*]Profile-based configuration system.
[*]Axes gain mining and combat XP; shields gain blocked-hit XP in either hand.
[*]Any item can level up with custom triggers.
[*]Configurable global, item-profile, and permission-based XP formulas.
[*]Configurable milestone rewards without automatic enchantments.
[*]Supports blacklisting/whitelisting for blocks, entities, and items.
[*]ActionBar notifications.
[*]Item lore modification.
[*]Optional enchanted-book blocking for AwkGearMastery items.
[*]Farming trigger support for fully grown player-planted crops.
[/LIST]

[CENTER][SIZE=5][B]AwkGearMastery 2026.1[/B][/SIZE][/CENTER]
[LIST]
[*][B]ARMOR_DURABILITY[/B] trigger awards XP when armor takes damage.
[*]Configurable XP formulas under [B]xp_formulas[/B], selectable per player via [B]awkgearmastery.formula.<id>[/B].
[*]Toggle to block enchanted books from being applied to AwkGearMastery items.
[*][B]block_data_storage[/B] option (SQLITE) for persisting per-block placement data.
[*]Farming trigger gains [B]ignore_player_placed_blocks_for_fully_grown_crops[/B].
[*]Fresh AwkGearMastery configuration and item data; no legacy migration.
[/LIST]

[CENTER][SIZE=5][B]Profile System[/B][/SIZE][/CENTER]
AwkGearMastery uses a modular profile-based configuration system. Any item can be configured to level up.

[SIZE=4][B]Profile Types[/B][/SIZE]
[TABLE]
[TR][TD][B]Profile Type[/B][/TD][TD][B]File[/B][/TD][/TR]
[TR][TD]Item Profiles[/TD][TD]item_profiles.yml[/TD][/TR]
[TR][TD]Trigger Profiles[/TD][TD]trigger_profiles.yml[/TD][/TR]
[TR][TD]Reward Profiles[/TD][TD]reward_profiles.yml[/TD][/TR]
[TR][TD]Display Profiles[/TD][TD]display_profiles.yml[/TD][/TR]
[/TABLE]

[SIZE=4][B]Trigger Types[/B][/SIZE]
[LIST]
[*]BLOCK_BREAK - XP when breaking blocks
[*]ENTITY_KILL - XP when killing entities
[*]FISHING - XP when catching items
[*]RIGHT_CLICK / LEFT_CLICK - XP on click
[*]CONSUME - XP when consuming items
[*]FARMING - XP when tilling soil and breaking fully-grown crops
[*]ARMOR_DURABILITY - XP when worn armor takes damage
[/LIST]

[SIZE=4][B]Default Supported Items[/B][/SIZE]
Out of the box, AwkGearMastery ships profiles for:
[LIST]
[*]Pickaxes, Axes, Shovels (block mining)
[*]Swords (combat)
[*]Bows, Crossbows (ranged)
[*]Fishing Rods (fishing)
[*]Tridents (combat / ranged)
[*]Hoes (farming)
[/LIST]
Add any item by creating custom profiles. See the [URL='https://github.com/s3tupw1zard/AwkGearMastery/wiki']Wiki[/URL] for details.
